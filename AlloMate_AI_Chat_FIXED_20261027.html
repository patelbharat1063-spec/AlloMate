SNP / genomic sample analysis

Import a CSV genotype table or SNP summary. This app can count marker calls and missingness, and summarize numeric trait columns if present. GBV / GEBV Review

Check readiness for breeding-value estimates; requires a documented population-validated model and suitable input data.

🧩

Advanced Mating Engine

Evidence-based candidate comparison from supplied records. Target traits: milk, fat/protein, early maturity/fertility; pedigree 60% + validated GEBV 40% where available; flag expected inbreeding above 6.25%.

Testing sequence: run each module with a harmless test first, then with authorized sample data. The AI must not invent results when pedigree, validated models, image quality, or clinical measurements are missing. Integration into live farm workflows should follow successful module testing.

☁️ Supabase Cloud Sync — Admin

Configure your own Supabase project, sign in with an administrator account, and synchronize records between this browser and your cloud database. Local IndexedDB remains enabled. Use the SQL setup file supplied with this HTML before connecting.

Security: only the Supabase project URL and publishable/anon key belong here. Never enter a service-role key. Create the admin user in Supabase Authentication first. Row-level security requires a signed-in user with trusted app_metadata role=admin and limits records to that user. Disable public sign-ups.

Sync strategy: push local records, then import cloud records missing locally. Matching IDs keep the local copy during merge; export a backup before first sync. Images embedded in records may use substantial database space; keep full local JSON backups.
